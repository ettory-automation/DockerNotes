#infraestrutura/devops/containers/container/docker #infraestrutura/devops/containers/container #infraestrutura/devops #infraestrutura/cli

* Listar opções de comandos para volumes:

```shell
docker volume
```

* Criar volume sem tuning:

```shell
docker volume create
```

* Listar volumes existentes:

```shell
docker volume ls
```

* Realizar inspect de volume:

```shell
docker inspect <volume_id>
```

* Remover volume:

```shell
docker volume rm <volume_id>
```

* Remover volumes não utilizados:

```shell
docker volume prune
```
