Para realizarmos as práticas com volume local, devemos primeiro realizar a criação de um volume, com o comando abaixo:

```shell
docker volume create nginx-html
```

* Verificando criação do volume:

```shell
docker volume ls | grep "nginx-html"
```

* Realizando montagem de volume no container:

```shell
docker run -d --mount type=volume,source=nginx-html,target=/usr/share/nginx/html nginx
```

Pode ser verificado com um _docker inspect_ no container criado, os dados sobre os volumes. Neste momento, todos os dados neste mountpoint estarão persistidos no volume montado.

* Também pode ser feito com o comando abaixo, portando menor verbosidade:

```shell
docker run -d -v <volume_name>:<mount_path_container> <image_name>
```

Neste exemplo:

```shell
docker run -d -v nginx-html:/usr/share/nginx/html nginx
```
