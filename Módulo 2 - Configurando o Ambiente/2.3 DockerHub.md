O Docker Hub é um Registry público, disponibilizado pela própria desenvolvedora do Docker, onde se é possível ter acesso à imagens globais.

Por padrão, o Docker puxa as imagens diretamente do Docker Hub. Caso seja necessário um comportamento distinto deste, deverá ser informado explicitamente ao Docker, qual será o Registry que ele irá utilizar para si.

Para enviar imagens para o Docker Hub, será necessário realizar um login no mesmo, com o comando abaixo:

```shell
docker login -u <username>
```

Logo após realizar o login, será criado no $HOME do usuário, um diretório de nome _.docker_, que irá armazenar suas credenciais do Registry que foi acessado, no arquivo _config.json_, entre outras configurações de segurança. Para acessá-lo, basta utilizar o seguinte comando:

```shell
cd $HOME/.docker
```


As credenciais em _config.json_ vão estar em _base64_. É possível decodificar esta string com o comando a seguir:

```shell
jq -r '.auths["https://index.docker.io/v1/"].auth' config.json | base64 -d
```

Vale a pena lembrar que a cada repositório configurado com o comando _docker login_, será realizada a entrada de novas credenciais de autenticação no arquivo _config.json_.


```ad-important
Em alguns Registries, quando se utiliza o comando _docker login_, ao invés de autenticar com usuário/senha, ele provisionará um token, que terá uma duração de vida. Quando este token expirar, será necessário realizar o login novamente com o comando _docker login_, para gerar um novo token de acesso. Isso é imprescindível para qualquer Registry que for utilizado, uma vez que os _docker pull_ e _docker push_ só são permitidos diretamente via Docker Hub nas configurações padrão.
```
