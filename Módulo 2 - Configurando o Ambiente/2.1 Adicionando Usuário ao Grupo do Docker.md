Para trabalhar com o usuário comum, isto é, sem privilégios administrativos, deve-se adicionar o usuário ao grupo do Docker.

1. Checando o grupo do docker:

```shell
getent group docker
```

Output:

_docker:x:984:_ -> Observar último campo vazio. Este é o campo de usuários adicionados ao grupo.

2. Adicionando usuário ao grupo docker:

```shell
sudo usermod -aG docker <username>
```

3. Atualizar grupo com modificação:

```shell
newgrp docker
```

4. Checar se o grupo docker está em execução na sessão atual:

```shell
id
```

5. Checar utilização do Docker fora do uso do root:

```shell
docker images
```
