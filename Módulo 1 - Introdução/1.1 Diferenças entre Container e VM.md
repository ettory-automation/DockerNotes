## Arquitetura: Virtual Machine (VM) vs Container

| Virtual Machine | Container                           |
| --------------- | ----------------------------------- |
| App A & App B   | App A & App B (isolated containers) |
| OS              | Container Engine (Docker)           |
| Hypervisor      | OS                                  |
| Hardware        | Hardware                            |

## Containers e Suas Premissas

* _Otimização de recursos_
* _Empacotamento_
* _Imutabilidade_
* _Deploy simplificado_

```ad-tip
***Containers compartilham o mesmo kernel*** do OS instalado no hardware, e ***são mais suscintos***. ***Virtual Machines criam kernels separados*** para si, e ***são mais completas***.
```
