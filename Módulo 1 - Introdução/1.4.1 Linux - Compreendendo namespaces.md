## O que são namespaces?

Namespaces são recursos de baixo nível do kernel Linux, que pode ser acessada facilmente pelo comando abaixo:

```shell
unshare --help
```

Existem vários tipos de namespaces, com focos diferentes para cada ocasião. Abaixo segue uma lista com alguns dos tipos mais comuns:

* UTS (hostname, etc.)
* System V IPC
* Mount
* Network
* PID
* User
* cgroup
* Time
* Entre outros...


Agora haverá a continuidade no isolamento do _chroot_, tratado no arquivo _[[1.4 Linux - Compreendendo chroot]]_.

## Isolamento de chroot com namespace (unshare)

Deve ser executado o comando abaixo para início desta etapa:

```shell
sudo unshare -p -f --mount-proc chroot .
```

Com isso, um processo isolado para o _chroot_ foi criado.

```ad-tip
Flags utilizadas:

* -p: indica a criação de um isolamento/namespace para PID. Ou seja, criação de um namespace para processo.
* -f: indica um fork no comando. No exemplo acima, o processo _chroot_ será filho do processo _unshare_. Caso o processo _unshare_ seja "morto", o filho deste, _chroot_, irá parar junto do processo pai.
* --mount-proc: realiza a montagem do diretório /proc do usuário corrente, no caminho selecionado logo após a nomeação do comando escolhido (neste caso, _chroot_)
```

Neste momento, o comando _ps_ não conseguirá mostrar em output, nem acessar os dados do sistema host sobre os processos em execução. Tendo assim, sua estrutura própria de /proc. Ou seja, possuímos um container criado com os seus pilares teóricos básicos: isolamento de processos e diretórios.

Estes dois passos são fundamentais para compreensão de isolamento, e sobre a containerização como um todo em sua base fundamental.

## Conclusão

Após isolarmos o diretório com o _chroot_, fizemos agora um isolamento de processos com o uso do recurso de manipulação de namespaces no sistema Linux, _unshare_. Isto é uma das etapas principais para execução dos pilares fundamentais dos containers.
