Agora, iremos explorar com maior profundidade a criação de uma network. 

Para verificarmos o que pode ser definido na criação de uma network, podemos utilizar o comando abaixo:

```shell
docker network create --help
```

Para realizar a criação da network de exemplo, iremos utilizar o comando abaixo, que será detalhado logo a seguir:

```shell
docker network create --attachable --driver bridge --subnet 10.53.0.0/24 --gateway 10.53.0.1 --ip-range 10.53.0.0/28 --internal internal-demo
```

- _\--attachable_: permite que containers standalone (fora do Docker Swarm) possam se conectar manualmente à rede.
    
- _\--driver bridge_: define que o driver da rede será do tipo bridge (ponte), permitindo comunicação entre containers no mesmo host.
    
- _\--subnet 10.53.0.0/24_: define o bloco de endereços IP da rede. Neste caso, a faixa vai de 10.53.0.0 a 10.53.0.255.
    
- _\--gateway 10.53.0.1_: define o IP do gateway da rede, normalmente atribuído ao host Docker para roteamento interno.
    
- _\--ip-range 10.53.0.0/28_: define um intervalo específico de IPs (de 10.53.0.0 a 10.53.0.15) que serão usados para alocação dinâmica de IPs dos containers.
    
- _\--internal_: cria uma rede isolada, sem acesso externo e sem acesso à internet. Os containers se comunicam apenas entre si dentro dessa rede.


Neste ponto, iremos criar um container para realizar um _attach_ nesta network:

```shell
docker run --network internal-demo -d nginx
```

* Também é possível designar um IP fixo para o container no momento da criação do mesmo, com a flag _\--ip_, como demonstrado abaixo:
  
```shell
docker run --network internal-demo --ip 10.53.0.10 -d nginx
```
