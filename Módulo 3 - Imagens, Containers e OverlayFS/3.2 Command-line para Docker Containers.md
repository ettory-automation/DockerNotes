#infraestrutura/devops/containers/container/docker #infraestrutura/devops/containers/container #infraestrutura/devops #infraestrutura/cli

* Listar opções de comandos para containers:

```shell
docker container
```

* Rodar container:

```shell
docker run <image_name>:<image_tag> 
```

Isto irá executar o container no modo _attach_. Isto significa que o container irá "travar" o uso do terminal, criando uma instância de execução única no TTY session.

Para utilizar o terminal juntamente à execução do container, podemos utilizar a flag _-d_, listada no comando _docker run --help_, para que o container seja executado no modo _detach_. Exemplo:

```shell
docker run -d <image_name>:<image_tag>
```

* Listar containers em execução:

```shell
docker ps
```

* Listar todos os containers (parados e em execução):

```shell
docker ps -a
```

* Realizar inspeção de container:

```shell
docker inspect <container_id>
```

* Realizar redirecionamento de portas no container:

```shell
docker run -d -p <host_port>:<container_port> <image_name>:<image_tag>
```

Também pode ser usada a flag _-P_ para que seja escolhida uma porta randômica para o redirecionamento, sem a necessidade de especificação:

```shell
docker run -d -P <image_name>:<image_tag>
```

 * Realizar verificação de logs do container:

```shell
docker logs <container_id>
```

A flag _-f_ pode ser utilizada para leitura em tempo real dos logs do container:

```shell
docker logs <container_id> -f
```

* Listar processos do container sem entrar no mesmo:

```shell
docker top <container_id>
```

* Utilizar o _attach_ para redirecionar as saídas do _stdin_, _stderr_ e _stdout_ para a sessão de terminal (não interativa):

```shell
docker attach <container_id>
```

```ad-warning
Caso este processo seja parado, o container será desligado juntamente com a "morte" do processo gerado pela execução do comando _attach_
```

* Verificar o status de consumo de recursos do container:

```shell
docker container stats <container_id>
```

* Executar comandos com binários existentes dentro de containers:

```shell
docker exec <container_id> <command>
```

* Realizar debugging dentro de container:

```shell
docker exec -it <container_id> <command>
```

A flag _-i_ faz com que o stdin do terminal do host se una (attach) ao stdin do terminal do container. Já a flag _-t_, faz com que seja alocado um pseudo-tty para aquele container identificado pelo ID.

* Pausar e retornar container em execução:

```shell
docker pause <container_id>
```

```shell
docker unpause <container_id>
```

* Remover containers individualmente com status stopped/exited:

```shell
docker rm <container_id>
```

Caso o container esteja em execução, se faz necessário o uso da flag _-f_ para realizar uma remoção forçada no container:

```shell
docker rm -f <container_id>
```

* Remover todos os container com status stopped/exited:

```shell
docker container prune
```

* Realizar stop em todos os containers em execução:

```bash
docker ps -q | xargs -I{} docker container stop {}
```
