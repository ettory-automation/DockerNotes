* Listar opções de comandos para imagens:

```shell
docker images
```

* Listar todas as imagens do Docker armazenadas no host:

``` shell
docker images
```

``` shell
docker image ls
```

* Realizar uma operação de _pull_ em uma imagem:

```shell
docker pull <image_name>:<image_tag>
```

```ad-important
Vale ressaltar a importância do uso de tags para versões exatas. Pois a não especificação de tag, leva o comando a dar um _pull_ na versão com a tag _latest_, ou seja, a mais recente. Porém, a cada vez que uma pipeline for executada, a nova imagem (caso seja atualizada no Registry) será baixada, e isto poderá ser uma complicação para as soluções em execução nos containers.

Para evitar este tipo de problema, sempre evite o uso da tag _latest_, e priorize a especificação exata da versão da imagem desejada no momento de uma operação _pull_.

Outra dica útil, é procurar por imagens com a tag contendo _alpine_, pois o Alpine Linux é uma distribuição muito compacta e limpa, gerando assim um controle melhor de recursos de armazenamento e fluidez no controle referente a pacotes instalados nos containers, de forma a otimizar o ambiente de soluções em containers.
```

* Realizar inspeção de imagem:

```shell
docker image inspect <image_name>:<image_tag>
```

Isto realiza um output que evidencia o conteúdo da imagem desejada.
