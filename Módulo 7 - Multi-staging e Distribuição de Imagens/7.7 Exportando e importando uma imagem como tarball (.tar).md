Para realizar os processos de exportação e importação de uma imagem compactada, deve-se seguir os seguintes passos:

1. Realizar o pull de uma imagem de um registry:

```bash
docker pull <image_name>
```

2. Realizar o salvamento desta imagem como _.tar_:

```bash
docker image save <image_name> -o <image_tar_name>.tar
```

3. Realizar o envio da imagem tarball para o host desejado utilizando netcat, SCP ou outro meio de transmissão de arquivos:

```bash
scp <image_tar_name_localhost>.tar <USER>@<HOST_IP>:<REMOTE_PATH>
```

4. Realizar o import da imagem no host remoto:

```bash
docker image load -i <image_name>.tar
```

> Possui pouco uso no dia a dia. Porém é muito útil para migrações offline de imagens entre hosts ou backup.
