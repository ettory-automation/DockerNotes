Para realizar o push de uma imagem para o registry DockerHub, deve-se seguir os seguintes passos:

1. Acessar o site do [DockerHub](https://hub.docker.com/) e realizar o login com uma conta válida
2. Criar um repositório no Console do DockerHub:
	*  Definir um nome para o repositório
	* Atribuir uma descrição
	* Escolher tipo de visibilidade (public | private)

3. Acessar a CLI do Docker:
	* Executar o comando _docker login_ e realizar o login com a conta válida do DockerHub

4. Realizar um git clone de um projeto com o comando do git cli : _git clone <git_repo_url>_
5. Coletar o _short hash_ do último commit realizado no repositório com o comando do git cli:  _git rev-parse --short HEAD_
6. Realizar a atribuição da tag com o comando do docker cli: _docker tag <image_name>:\<tag1> \<registry>/\<repository>:<tag2>-<short_hash>_
7. Realizar o push da Docker Image para o registry com o comando do docker cli: _docker push \<registry>/\<repository>:<tag2>-<short_hash>_
