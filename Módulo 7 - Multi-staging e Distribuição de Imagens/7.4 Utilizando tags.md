* Modo simplificado utilizando somente uma tag com o parâmetro _-t_:

```bash
docker build -t <image>:<tag> .
```

* Utilizando múltiplas tags:

```bash
docker tag <image>:<tag1> <registry>/<repository_name>:<tag2>
```

> Para registries privados ou externos (diferentes do DockerHub) é necessário informar o registry na sintaxe do comando. Porém, se for utilizar o DockerHub (docker.io), essa identificação explícita não é necessária, tornando-se opcional.
