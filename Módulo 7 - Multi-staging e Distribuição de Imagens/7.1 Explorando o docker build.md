Neste capítulo será abordado diferentes formas de se criar uma imagem a partir de um _Dockerfile_ utilizando o _docker build_.

* Estrutura base do comando _docker build_:

```bash
docker build [OPTIONS] PATH | URL | -
```

Onde:

1. **Path**: Citação de um Dockerfile no host (**local**)
2. **URL**: Citação de um Dockerfile localizado remotamente (**remoto**)
3. **stdin (-)**: Citação de um Dockerfile pelo **stdin** do _docker build_ (bash-based / equivalente ao uso de PIPE (" | ") )

## Casos de Uso

1. **Path**:

```bash
docker build -t nginx:path .
```

2. **URL**:

> Estrutura de URL: **\<git url>#\<tag | branch>:\<directory>**

```bash
docker build -t app:1.0 https://github.com/user/repo.git#main:directory_repo
```

3. **stdin (-)**:

```bash
docker build -t nginx:stdin - <<EOF
FROM nginx
RUN apt update
EOF
```

Para visualizar mais possibilidades, verificar no [manual oficial](https://docs.docker.com/build/) do _docker build_.
